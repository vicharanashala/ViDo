The idea

A plan that understands your life.

ViDo’s long-term goal is to learn from how you complete tasks and help you build a schedule that fits.

A future suggestion could consider:

  • Your commitments
  • Task priority
  • Past progress

Then help you find a better day or spot a deadline at risk.

You decide what happens next.

Tasks, deadlines, calendar events, and checkpoints are the foundations being built today.

Everyday work

Give each task a place to begin.

01

Capture the responsibility

Add a title and deadline, with a description, priority, or start date when useful. A task can be a home repair, a study session, or a work deliverable.

02

Show how it’s moving

Mark a personal task complete or reopen it to record the change in its history. On an assigned team task, update the percentage and add a checkpoint about what changed.

03

Finish and look back

Completed and archived views keep past work accessible. The dashboard surfaces the work that needs your attention today.

Getting started

Set up your first day.

Take a look around with the sample workspace, then add a task and see how it fits into your plans.

Open the local product preview →

  1. Choose how to enter

    Open the preview to explore as Demo User without signing in. To use a personal workspace where sign-in is configured, choose Continue with Google on the landing page and complete the sign-in prompt.

  2. Add your first task

    Choose New Task in the sidebar. Enter a Task Title and Target Due Date. Add a description, start date, due time, or priority if useful, then select Create Task.

  3. Make a plan

    Use the dashboard and task views to see what is due. Open Calendar in the sidebar to explore your week or month and add events alongside tasks.

  4. Keep progress visible

    Open a personal task and choose Mark as Complete. Find it in Completed and choose Reopen Task if more work comes up. Use Analytics to see completed work and planning targets.

The preview starts with sample tasks. Reloading the preview restores its sample tasks. In the signed-in workspace, saving tasks, calendar events and targets requires the local backend. See the local service setup to run it.

Run it on your computer

Set up the local preview

Follow these steps to run ViDo on your own computer. You’ll need a terminal, Node.js and npm, and Git.

  1. Download the project. Open a terminal and run: 
    git clone https://github.com/vicharanashala/ViDo.git
cd ViDo

    If you already have the project, open its folder in your terminal instead.

  2. Install and start ViDo. From the project folder, run: 
    npm install
npm run dev

    Keep this terminal open. Open the local address printed by Vite, usually http://localhost:5173, then choose Live Preview. If port 5173 is occupied, use the address printed in the terminal.

  3. Try local sign-in. The preview works without sign-in. For a personal workspace using mock accounts, install Firebase CLI and a compatible Java runtime, then check the first terminal. If the emulators are already running, continue to sign-in. Otherwise, run this in a second terminal from the project folder: 
    npm run emu

    Return to the local landing page, choose Continue with Google, and select a mock account in the emulator prompt. The local demo uses test accounts and does not require real Google credentials.

The app attempts to start missing emulators automatically when available. If sign-in cannot connect, check that the emulator terminal is running. To stop a running terminal command, press Ctrl + C. For full setup and team backend details, see the project README and developer setup guide.
