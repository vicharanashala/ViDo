# ViDo Professional

A polished, more focused copy of the expressive ViDo workspace.

## Kept

- Quick add, Today/Upcoming/Past/Completed/Archived.
- Progress, checkpoints, task detail.
- Local auth, profile, reminders, local-browser sharing.
- Task images and task paths from Task details.

## Reduced

- Standard navigation labels only.
- No Momentum trail in the main workspace.
- No floating background doodles.
- No quote above the Today queue.
- System clock sits at the far right of the quick-add row.

## Run

```bash
npm install
npm run dev
```
